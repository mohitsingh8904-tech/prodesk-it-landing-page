# Prodesk IT – Corporate Landing Page

A modern, responsive and premium corporate landing page developed for **Prodesk IT's Digital Marketing Wing** as part of the Prodesk IT internship project.

## Project Overview

The Prodesk IT Corporate Landing Page showcases digital services through a clean, professional and responsive interface. It is designed to provide visitors with a smooth browsing experience across desktop, tablet and mobile devices.

## Features

- Responsive navigation bar with mobile hamburger menu.
- Modern hero section with clear call-to-action buttons.
- About section introducing Prodesk IT.
- Three service cards:
  - Web Development
  - Search Engine Optimization (SEO)
  - Digital Marketing
- Dark and Light theme toggle.
- Theme preference saved using Local Storage.
- Sticky navigation bar.
- Smooth navigation between sections.
- Interactive hover effects.
- Responsive layouts for desktop, tablet and mobile.
- Semantic HTML and accessibility improvements.

## Technologies Used

- HTML5
- CSS3 (Flexbox and Grid)
- Vanilla JavaScript
- Browser Local Storage
- Google Chrome Lighthouse
